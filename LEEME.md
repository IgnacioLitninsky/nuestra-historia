# Nuestra historia · Capítulo 1

## Editar
- **Textos** (diálogos, carta, frasco, secretos, fechas): `textos.js`.
- **Fotos**: carpeta `fotos/` (ver `fotos/LEEME.txt`).

## Probar antes de regalarlo
Abrí `index.html` con doble clic (o la página ya publicada) y agregá al final de la dirección:
- `?debug` → sin contraseña, todos los niveles abiertos, tecla **W** = ganar el minijuego.
- `?reset` → borra el progreso de ESE navegador (usalo antes de entregarlo si lo probaste en el celu de ella).
- `?fecha=2026-10-26` → simula esa fecha para ver las cartas sorpresa.

## Publicar en GitHub Pages
1. Repositorio llamado `nuestra-historia` (si usás otro nombre, cambiá la línea `og:image` de `index.html`).
2. Subí el **contenido** de esta carpeta (no la carpeta) a la rama `main`.
3. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
4. Link: `https://ignaciolitninsky.github.io/nuestra-historia/`

Cada vez que subas cambios, el link es el mismo y el progreso de ella se conserva.
